# 封装模块 Skill

## 功能说明

本 Skill 专门用于将已测试成功的代码封装成生产环境可用的模块。

## 封装流程

### 1. 确认测试完成

在封装前，确保代码已经过充分测试：
- ✅ 浏览器检测和连接功能正常
- ✅ 登录流程完整
- ✅ 截图功能正常
- ✅ 浏览器保持打开功能正常
- ✅ 无 timeout 设置

### 2. 创建模块目录

```
执行模块/
├── 模块名称/
│   ├── __init__.py
│   ├── 主模块.py
│   ├── browser.py (如果需要)
│   ├── 使用说明.md
│   └── README.md
└── 相关配置/
```

### 3. 封装标准

#### 代码结构
```python
"""
模块名称 - 功能说明

功能集成：
1. 检测现有浏览器
2. 连接现有浏览器
3. 多标签管理
4. 智能打开/切换

永久保持：
5. 永久保持浏览器
6. 不设置 timeout
"""
import sys
import os

# 添加模块路径
sys.path.insert(0, os.path.dirname(__file__))

# 导入依赖
from browser import get_page, screenshot, wait, list_pages

# 主逻辑
def main():
    pass

if __name__ == "__main__":
    main()
```

#### 必需功能
1. 浏览器检测和连接
2. 错误处理
3. 日志输出
4. 截图功能
5. 保持浏览器打开

#### 禁止内容
- ❌ timeout 设置
- ❌ 关闭浏览器代码
- ❌ headless=True（除非特殊需求）

### 4. 文档要求

每个封装模块必须包含：

#### README.md
```markdown
# 模块名称

## 功能说明
简短描述模块功能

## 使用方法
```bash
python 执行模块/模块名称/主模块.py
```

## 依赖
- Python 3.12
- playwright
- 其他依赖...

## 配置
说明需要的配置文件和格式
```

#### 使用说明.md
```markdown
# 使用说明

## 功能特性
详细列出所有功能

## 使用示例
提供多种使用方式的示例

## 常见问题
列出常见问题和解决方案

## 注意事项
使用时的注意事项
```

### 5. 测试验证

封装完成后，进行以下测试：

1. **独立运行测试**
   ```bash
   python 执行模块/模块名称/主模块.py --help
   ```

2. **功能测试**
   - 运行完整流程
   - 验证所有功能正常

3. **浏览器保持测试**
   - 脚本退出后浏览器应保持打开

4. **文档验证**
   - 检查文档是否完整
   - 验证示例代码是否正确

### 6. 版本管理

每个封装模块应有版本标识：

```python
__version__ = "1.0.0"
__author__ = "纳税申报团队"
__date__ = "2026-02-28"
```
