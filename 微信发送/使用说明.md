# 微信自动发送工具 - 使用说明

## 📁 文件位置

**程序**: `微信自动发送.py`
**数据文件**: `微信发送\微信发送.csv`（或 .xlsx）

## 📋 数据文件格式

### Excel 格式 (.xlsx)

| A 列 | B 列 | C 列 |
|------|------|------|
| **微信名称** | **文件路径** | **消息内容** |
| 张三 | C:\文件 1.pdf | 您好，这是文件 |
| 李四 | C:\文件 2.docx | 请查收附件 |

### CSV 格式（备用）

```csv
微信名称，文件路径，消息内容
张三，C:\文件 1.pdf，您好，这是文件
李四，C:\文件 2.docx，请查收附件
```

## 🚀 使用步骤

### 1. 准备数据文件

编辑 `微信发送\微信发送.csv` 文件：
- A 列：微信联系人名称（必须与微信中完全一致）
- B 列：要发送的文件路径
- C 列：要发送的文字消息

### 2. 安装依赖

```bash
# 安装 openpyxl（读取 Excel）
C:\Users\15606\miniconda3\envs\tax_python\python.exe -m pip install openpyxl
```

### 3. 运行程序

```bash
C:\Users\15606\miniconda3\envs\tax_python\python.exe 微信自动发送.py
```

### 4. 确认发送

程序会显示数据预览，输入 `y` 确认发送。

### 5. 手动发送

程序会将文件复制到微信文件夹，需要打开微信手动点击发送。

## 📊 工作原理

1. **读取 Excel/CSV** - 获取发送列表
2. **查找微信目录** - `C:\Users\用户名\Documents\WeChat Files\`
3. **复制文件** - 到对应聊天的 Attachment 目录
4. **保存消息** - 保存为 txt 文件（因为无法直接输入文字）
5. **统计结果** - 显示成功/失败数量

## ⚠️ 注意事项

### 微信名称必须准确
- 如果微信名是"张三"，Excel 中必须写"张三"
- 如果微信名是"张三 (公司)"，必须写"张三 (公司)"
- 群聊名称同理

### 文件路径必须存在
- 确保 B 列的文件路径真实存在
- 使用绝对路径（如 C:\...\文件.txt）

### 消息内容限制
- 由于技术限制，文字消息保存为 txt 文件
- 需要手动复制粘贴到微信输入框

## 🔧 故障排除

### 问题 1：提示未找到微信目录
**解决**: 确认微信已安装并登录

### 问题 2：发送失败
**解决**: 
1. 检查微信名称是否准确
2. 检查文件路径是否存在
3. 关闭微信后重试

### 问题 3：无法读取 Excel
**解决**: 
1. 安装 openpyxl：`pip install openpyxl`
2. 或使用 CSV 格式
