# 微信发送工具 - Windows 7 兼容版

## 文件信息

**文件名**: `微信发送工具_Win7.exe`
**大小**: 约 6.3 MB
**系统要求**: Windows 7/8/10/11
**Python 版本**: 无需安装 Python

## 使用方法

### 1. 直接运行
双击 `微信发送工具_Win7.exe` 即可运行

### 2. 功能说明
- 选择要发送的文件（登录模块、浏览器管理模块、使用说明等）
- 选择微信账号
- 选择发送对象（文件传输助手或特定聊天）
- 自动复制文件到微信文件夹

### 3. 注意事项
- 微信必须已安装并登录
- 微信文件目录：`~/Documents/WeChat Files/`
- 文件会复制到微信文件夹，需要手动点击发送

## 兼容性

- ✅ Windows 7 (32/64 位)
- ✅ Windows 8/8.1
- ✅ Windows 10
- ✅ Windows 11
- ❌ Windows XP (不支持)

## 如果遇到问题

### 问题 1：找不到微信文件目录
**解决**: 确认微信已安装并登录，检查目录 `C:\Users\你的用户名\Documents\WeChat Files\`

### 问题 2：文件复制失败
**解决**: 关闭微信后重试，或检查文件是否被占用

### 问题 3：Windows 7 无法运行
**解决**: 
1. 右键点击 → 以管理员身份运行
2. 确保已安装 .NET Framework 4.5 或更高版本
