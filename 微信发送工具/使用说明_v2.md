## ✅ 功能特性

### 1. 单发模式
- 发送到一个指定的聊天
- 支持选择聊天或输入聊天名称
- 可发送到文件传输助手

### 2. 群发模式
- 发送到多个聊天
- 支持全选（all）
- 支持选择部分（输入序号，如 1,3,5）
- 显示发送统计（成功/失败数量）

### 3. 自动检测
- 自动检测微信安装目录
- 自动检测所有微信账号
- 自动获取聊天列表

### 4. 文件选择
- [1] 登录模块 (登录.py)
- [2] 浏览器管理模块 (browser.py)
- [3] 使用说明文档 (使用说明.md)
- [4] 自定义文件

## 🚀 使用步骤

### 单发模式

1. **双击运行**
   ```
   微信发送工具_Win7.vbs
   ```

2. **选择微信账号**（如果有多个）
   ```
   输入序号，默认 1
   ```

3. **选择文件**
   ```
   按 1-4 选择要发送的文件
   ```

4. **选择发送模式**
   ```
   按 1 选择单发模式
   ```

5. **选择聊天**
   ```
   输入序号或聊天名称
   输入 0 发送到文件传输助手
   ```

6. **完成**
   ```
   ✓ 文件已复制到微信文件夹
   请在微信中手动发送
   ```

### 群发模式

1-3. 同上

4. **选择群发模式**
   ```
   按 2 选择群发模式
   ```

5. **选择要发送的聊天**
   ```
   输入序号，用逗号分隔（如：1,3,5）
   或输入 all 发送给所有聊天
   ```

6. **查看统计**
   ```
   群发完成！
   成功：5 个
   失败：0 个
   ```

## ⚠️ 注意事项

1. **微信必须已安装并登录**
   - 程序需要访问微信文件目录
   - 路径：`C:\Users\用户名\Documents\WeChat Files\`

2. **文件需要手动发送**
   - 程序只复制文件到微信文件夹
   - 需要在微信中点击发送按钮

3. **聊天名称要准确**
   - 如果手动输入聊天名称，必须与微信中完全一致

## 🔧 故障排除

### 问题 1：未找到微信文件目录
**解决**:
1. 确认微信已安装
2. 确认微信已登录
3. 检查目录是否存在

### 问题 2：复制失败
**解决**:
1. 关闭微信后重试
2. 检查文件是否被占用
3. 确认目标目录有写入权限

### 问题 3：双击没反应
**解决**:
1. 右键 → 打开方式 → Microsoft Windows Based Script Host
2. 或右键 → 属性 → 打开方式 → 更改 → Windows Script Host
