# 微信发送工具 - 版本说明

## 📁 可用版本

### 1. VBScript 版本 ⭐ **推荐用于 Windows 7**

**文件**: `微信发送工具_Win7.vbs`

**兼容性**: 
- ✅ Windows 7 (100%)
- ✅ Windows 8/8.1
- ✅ Windows 10
- ✅ Windows 11

**使用方法**:
```
双击 微信发送工具_Win7.vbs 即可运行
```

**特点**:
- 无需安装任何软件
- 无需 Python 环境
- 纯脚本，系统原生支持
- 支持单发和群发功能

---

### 2. Python 打包版本 ⚠️ **仅 Windows 10/11**

**文件**: `微信发送工具_Win7.exe`

**兼容性**: 
- ❌ Windows 7 - **不支持**（需要 api-ms-win-core-path-l1-1-0.dll）
- ❌ Windows 8/8.1 - **不支持**
- ✅ Windows 10 - 需要更新到最新版
- ✅ Windows 11

**使用方法**:
```
双击 微信发送工具_Win7.exe 即可运行
```

**特点**:
- 独立 EXE 文件
- 需要 .NET Framework 4.5+
- 需要 Windows 10 最新版

---

## ⚠️ 重要说明

### Windows 7 用户

**请使用 VBScript 版本（.vbs 文件）！**

由于技术限制：
- Python 3.12 打包的 EXE 需要 Windows 10 的 DLL 文件
- Python 3.8 是最后一个支持 Win7 的版本，但打包环境有问题

**VBScript 版本是 Windows 7 的最佳选择**：
- 系统原生支持
- 无需安装任何东西
- 功能完整（单发 + 群发）

### Windows 10/11 用户

两个版本都可以使用：
- `.vbs` - 轻量，无需打包
- `.exe` - 独立程序，但体积较大

## 📞 故障排除

### 问题 1：EXE 版本提示缺少 api-ms-win-core-path-l1-1-0.dll
**解决**: 这是 Windows 7 系统文件，无法单独安装。请使用 VBScript 版本。

### 问题 2：VBS 版本双击没反应
**解决**: 
1. 右键 → 打开方式 → Microsoft Windows Based Script Host
2. 或检查是否被杀毒软件拦截

### 问题 3：找不到微信目录
**解决**:
1. 确认微信已安装并登录
2. 检查目录：`C:\Users\用户名\Documents\WeChat Files\`
