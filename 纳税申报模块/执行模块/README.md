# 执行模块 - 生产环境使用

## 说明

本目录包含所有已测试成功的封装模块，用于生产环境。

## 包含内容

1. **登录模块** - 浙江省电子税务局自动登录
2. **浏览器管理** - 浏览器检测、连接、多标签管理
3. **使用说明** - 各模块的使用文档

## 使用方法

### 登录模块

```bash
# 运行登录（默认前台保持打开）
python 执行模块/登录.py

# 后台无头模式
python 执行模块/登录.py --headless

# 自动完成验证码
python 执行模块/登录.py --auto-verify
```

### 代码调用

```python
from 执行模块.登录 import 登录

# 执行登录
登录 ()
```

## 功能特性

1. ✅ 检测现有浏览器并连接
2. ✅ 多标签管理
3. ✅ 智能打开/切换页面
4. ✅ 永久保持浏览器（不关闭）
5. ✅ 无 timeout 限制

## 依赖

- Python 3.12
- playwright
- openpyxl
- psutil
