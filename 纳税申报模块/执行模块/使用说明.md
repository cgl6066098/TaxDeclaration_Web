## 功能特性

### 浏览器管理 (browser.py)

1. **检测现有浏览器** - 使用 CDP 端口检测 Edge 是否运行
2. **连接现有浏览器** - 通过 CDP 连接到已有 Edge
3. **多标签管理** - 列出所有页面，找到匹配的标签
4. **智能打开** - 不在目标页面时打开/切换到新标签
5. **永久保持浏览器** - 脚本退出后浏览器继续运行
6. **不设置 timeout** - 没有任何超时限制

### 登录模块 (登录.py)

- 从 Excel 自动读取登录信息
- 自动访问税务局网站
- 自动点击"代理业务"
- 自动填写社会信用代码、手机号、密码
- 自动点击登录
- 等待手动完成验证码
- 保持浏览器打开

## 使用方法

### 方法 1：双击批处理文件

```
双击：执行模块 - 登录.bat
```

### 方法 2：命令行运行

```bash
# 进入项目目录
cd C:\Users\15606\Desktop\AI_Project\纳税申报

# 运行登录模块（默认前台保持打开）
python 执行模块/登录.py

# 后台无头模式
python 执行模块/登录.py --headless

# 自动完成验证码（跳过手动确认）
python 执行模块/登录.py --auto-verify

# 测试后关闭浏览器
python 执行模块/登录.py --no-keep-alive
```

### 方法 3：代码调用

```python
from 执行模块.登录 import 登录

# 执行登录（默认前台保持打开）
登录 ()

# 后台模式
登录 (headless=True)

# 自动验证
登录 (auto_verify=True)

# 不保持打开
登录 (keep_alive=False)
```

### 方法 4：使用类

```python
from 执行模块.登录 import TaxLogin

login = TaxLogin()
login.read_login_info()     # 读取 Excel 中的账号密码
login.start()               # 获取浏览器
login.login()               # 执行登录
login.wait_for_verify()     # 等待验证码完成
login.wait()                # 保持运行
```

## 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--headless` | 无头模式（后台运行，不显示窗口） | `False` |
| `--keep-alive` | 保持浏览器打开 | `True` ✅ |
| `--no-keep-alive` | 不保持浏览器打开（完成后关闭） | `False` |
| `--auto-verify` | 自动完成验证码（跳过手动确认） | `False` |

## 常见问题

### Q: 浏览器启动失败？
A: 确保系统已安装 Microsoft Edge 浏览器

### Q: 登录信息读取失败？
A: 检查 Excel 文件路径和表头格式是否正确

### Q: 如何手动完成验证码？
A: 在浏览器窗口中点击验证码字符，然后按回车键继续

### Q: 如何完全关闭浏览器？
A: 使用 `--no-keep-alive` 参数，或手动关闭 Edge 窗口

## 注意事项

1. **Excel 文件必须存在** - 确保 `员工登录方式/登录密码.xlsx` 文件存在
2. **表头关键字匹配** - 表头必须包含"纳税人识别号"、"手机号"、"密码"等关键字
3. **浏览器保持打开** - 默认情况下登录完成后浏览器保持打开，按 Ctrl+C 关闭脚本
4. **验证码处理** - 登录会显示验证码弹窗，需要手动完成
