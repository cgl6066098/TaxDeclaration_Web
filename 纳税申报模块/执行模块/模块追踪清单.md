**更新时间**: 2026-02-28

## 模块清单

### 1. browser.py - 浏览器管理器（核心基础模块）

**功能**:
- 检测现有 Edge 浏览器（CDP 端口 9222）
- 连接现有浏览器或创建新浏览器
- 多标签页管理
- 根据 URL 智能打开/切换标签
- 永久保持浏览器（不关闭）
- 截图功能

**导出函数**:
```python
get_page(headless=False)           # 获取页面
get_page_by_url(url_contains)      # 根据 URL 获取/创建页面
screenshot(name)                   # 截图
list_pages()                       # 列出所有页面
set_keep_alive(keep_alive)         # 设置是否保持浏览器
wait(message)                      # 保持运行
```

**依赖**: playwright, psutil, subprocess

**被依赖**: 登录.py 及所有后续模块

---

### 2. 登录.py - 税务局登录模块

**功能**:
- 从 Excel 读取登录信息
- 调用 browser.py 连接浏览器
- 访问浙江省电子税务局
- 点击"代理业务"
- 填写社会信用代码、手机号、密码
- 点击登录
- 等待验证码（手动完成）
- 保持浏览器打开

**导出函数/类**:
```python
登录 (headless, keep_alive, auto_verify)  # 快捷登录函数
TaxLogin                                   # 登录类
```

**依赖**: browser.py, openpyxl

**被依赖**: 无（顶层业务模块）

**配置**:
- `员工登录方式/登录密码.xlsx`

## 完整流程（当前）

```
1. browser.py 启动/连接浏览器
   ↓
2. 登录.py 读取 Excel
   ↓

   ↓
4. 浏览器保持打开（等待下一步操作）
```
