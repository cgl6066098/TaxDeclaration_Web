# 浏览器管理器使用说明

## 核心理念

**所有代码运行第一步：检测浏览器是否已打开，没有则打开**

## 文件位置
`纳税申报模块/browser.py`

## 使用方法

### 方法 1：直接导入便捷函数

```python
from 纳税申报模块.browser import get_page, screenshot

# 获取页面（浏览器未打开则自动打开）
page = get_page()

# 使用页面
page.goto("https://example.com")

# 截图
screenshot("test")
```

### 方法 2：使用浏览器管理器类

```python
from 纳税申报模块.browser import browser_manager

# 获取或创建浏览器
playwright, browser, context, page = browser_manager.get_or_create()

# 使用页面
page.goto("https://example.com")
```

## 浏览器检测逻辑

```python
def get_page() -> Page:
    """
    1. 检查是否有 BrowserManager 实例
    2. 检查浏览器是否还活着
    3. 如果活着，返回现有页面
    4. 如果死了，清理并创建新浏览器
    5. 如果从未创建，创建新浏览器
    """
```

## 特点

1. **单例模式** - 全局只有一个浏览器实例
2. **自动检测** - 自动检测浏览器是否运行
3. **永不关闭** - 代码中不包含关闭浏览器的逻辑
4. **截图自动保存** - 截图自动保存到 screenshots 目录

## 示例代码

### 完整示例

```python
from 纳税申报模块.browser import get_page, screenshot
import time

# 第一步：获取浏览器（未打开则自动打开）
page = get_page()

# 使用浏览器
page.goto("https://www.zhihu.com")
page.wait_for_load_state("networkidle")

# 截图
screenshot("zhihu")

# 保持运行
while True:
    time.sleep(1)
```

### 登录示例

```python
from 纳税申报模块.browser import get_page, screenshot
from 纳税申报模块.登录 import TaxLogin

# 登录（自动使用已有浏览器或创建新浏览器）
login = TaxLogin()
login.read_login_info()
login.start()  # 这里会调用 get_page()
login.login()

# 保持运行
login.wait()
```

## 注意事项

1. **不要关闭浏览器** - 所有代码都不包含 `browser.close()` 或 `context.close()`
2. **浏览器永久运行** - 浏览器一旦打开就会一直运行
3. **手动关闭** - 需要手动关闭 Edge 浏览器进程
4. **进程检测** - 使用 psutil 检测 Edge 进程是否存在

## 依赖

- playwright (浏览器自动化)
- psutil (进程检测)

## 常见问题

**Q: 如何完全关闭浏览器？**
A: 手动关闭所有 Edge 浏览器窗口，或运行任务管理器结束进程

**Q: 浏览器卡住了怎么办？**
A: 关闭所有 Edge 窗口，重新运行脚本会自动创建新浏览器

**Q: 可以在多个脚本间共享浏览器吗？**
A: 可以，所有脚本都使用同一个 browser_manager 单例
