# 浏览器配置说明

## 命令行参数

所有测试和生产脚本都支持以下参数：

### `--headless`
后台无头模式，不显示浏览器窗口

```bash
python test_click.py --headless
```

### `--keep-alive` （默认）
保持浏览器打开，脚本退出后浏览器继续运行

```bash
python test_click.py --keep-alive
# 或者直接不传参数，默认就是保持打开
python test_click.py
```

### `--no-keep-alive`
不保持浏览器打开，完成后关闭

```bash
python test_click.py --no-keep-alive
```

### `--auto-verify`
自动完成验证码（跳过手动确认，等待 5 秒）

```bash
python test_click.py --auto-verify
```

## 使用示例

### 示例 1：默认模式（前台保持打开）
```bash
python test_click.py
```
- ✅ 显示浏览器窗口
- ✅ 保持打开，不关闭

### 示例 2：后台运行
```bash
python test_click.py --headless --auto-verify
```
- ❌ 不显示窗口
- ✅ 自动完成验证

### 示例 3：测试后关闭
```bash
python test_click.py --no-keep-alive
```
- ✅ 显示浏览器窗口
- ❌ 完成后关闭

### 示例 4：登录模块
```bash
# 保持打开
python 纳税申报模块/登录.py

# 后台运行
python 纳税申报模块/登录.py --headless --auto-verify

# 测试后关闭
python 纳税申报模块/登录.py --no-keep-alive
```

## 代码中使用

```python
from 纳税申报模块.browser import get_page, set_keep_alive, wait

# 方法 1：通过参数控制
page = get_page(headless=False, keep_alive=True)

# 方法 2：动态设置
set_keep_alive(True)   # 保持打开
set_keep_alive(False)  # 完成后关闭

# 保持运行
wait("浏览器保持打开")
```

## 默认行为

**默认配置：**
- `headless=False` - 显示浏览器窗口
- `keep_alive=True` - 保持浏览器打开
- `auto_verify=False` - 等待手动完成验证码

**除非明确指定，否则浏览器始终保持打开状态！**
