# 登录模块使用说明

## 文件位置
`纳税申报模块/登录.py`

## 功能说明
从 Excel 自动读取登录信息，完成浙江省电子税务局的登录流程。

## 使用方法

### 方法 1：直接运行脚本
```bash
C:\Users\15606\miniconda3\envs\tax_python\python.exe 纳税申报模块\登录.py
```

### 方法 2：代码调用
```python
from 纳税申报模块.登录 import 登录

# 执行登录（浏览器保持打开）
登录 ()
```

### 方法 3：关闭浏览器模式
```python
from 纳税申报模块.登录 import 登录

# 执行登录后自动关闭浏览器
登录 (keep_open=False)
```

### 方法 4：无头模式
```python
from 纳税申报模块.登录 import 登录

# 无头模式（不显示浏览器窗口）
登录 (headless=True)
```

## 登录信息配置

登录信息从以下 Excel 文件读取：
```
纳税申报模块/员工登录方式/登录密码.xlsx
```

### Excel 格式要求

| 列 A | 列 B | 列 C | 列 D |
|------|------|------|------|
| **单位** | **纳税人识别号** | **手机号** | **个人用户密码** |
| 穗通财务 | 913301040709922876 | 15606523222 | Cgl@6066098 |

**表头关键字：**
- 纳税人识别号 / 社会信用代码 → 自动识别为社会信用代码
- 手机号 → 自动识别为手机号码
- 密码 → 自动识别为登录密码

## 登录流程

1. **启动浏览器** - 打开 Microsoft Edge
2. **访问登录页面** - 浙江省电子税务局统一登录
3. **点击代理业务** - 切换到代理业务登录方式
4. **填写信息** - 自动填写社会信用代码、手机号、密码
5. **点击登录** - 提交登录
6. **验证码** - 显示验证码弹窗（需手动完成）

## 类结构

```python
class TaxLogin:
    """税务登录类"""
    
    def __init__(self, headless=False)
    def read_login_info(self) -> 'TaxLogin'
    def start(self) -> 'TaxLogin'
    def login(self, keep_open=True) -> 'TaxLogin'
    def wait()
    def close()
```

## 示例代码

### 完整示例
```python
from 纳税申报模块.登录 import TaxLogin

# 创建登录实例
login = TaxLogin()

# 读取登录信息
login.read_login_info()

# 启动浏览器
login.start()

# 执行登录
login.login(keep_open=True)

# 保持浏览器打开
login.wait()
```

### 使用上下文管理器
```python
from 纳税申报模块.登录 import TaxLogin

with TaxLogin() as login:
    login.read_login_info()
    login.login()
# 退出 with 块时自动关闭浏览器
```

## 注意事项

1. **Excel 文件必须存在** - 确保 `员工登录方式/登录密码.xlsx` 文件存在
2. **表头关键字匹配** - 表头必须包含"纳税人识别号"、"手机号"、"密码"等关键字
3. **浏览器保持打开** - 默认情况下登录完成后浏览器保持打开，按 Ctrl+C 关闭
4. **验证码处理** - 登录会显示验证码弹窗，需要手动完成

## 依赖库

- playwright (浏览器自动化)
- openpyxl (Excel 读取)

## 常见问题

**Q: 浏览器启动失败？**
A: 确保系统已安装 Microsoft Edge 浏览器

**Q: 登录信息读取失败？**
A: 检查 Excel 文件路径和表头格式是否正确

**Q: 验证码如何自动完成？**
A: 当前版本需要手动完成验证码，后续可扩展自动识别功能
