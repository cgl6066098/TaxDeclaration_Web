# 登录功能使用说明

## 已完成功能

### 1. 知乎登录

**文件位置:** `纳税申报模块/login.py`

**使用方法:**

```python
from 纳税申报模块.login import Login

# 创建登录实例
login = Login()
login.start()

# 登录知乎（不带账号密码，手动输入）
login.login_zhihu()

# 保持浏览器打开
login.wait()
```

**带账号密码登录:**

```python
from 纳税申报模块.login import login_zhihu

# 自动填写账号密码
login_zhihu(username="你的手机号", password="你的密码")
```

### 2. 页面识别和点击

登录模块使用 Playwright 的文本识别功能：

```python
# 查找元素
pwd_tab = page.locator('text=密码登录').first

# 检查可见性
if pwd_tab.is_visible():
    pwd_tab.click()

# 填写表单
page.locator('input[type="text"]').first.fill(username)
page.locator('input[type="password"]').first.fill(password)

# 点击登录
page.locator('button:has-text("登录")').first.click()
```

## 登录流程

1. 启动浏览器（Edge）
2. 访问知乎登录页面
3. 识别当前登录方式（验证码登录/密码登录）
4. 点击"密码登录"切换
5. （可选）填写账号密码
6. 截图保存
7. （可选）点击登录按钮

## 注意事项

1. 首次运行可能需要安装 Playwright 驱动
2. 确保系统已安装 Microsoft Edge 浏览器
3. 如果浏览器启动失败，尝试关闭所有 Edge 进程后重试
4. 账号密码建议手动输入，避免明文存储在代码中
